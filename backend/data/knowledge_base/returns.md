# Returns, Exchanges & Refunds

## Return policy
You can return any unused item in its original packaging within 60 days of delivery for a full refund. Items marked "Final Sale" cannot be returned. Fernway Rewards members get an extended 90-day return window.

## How to start a return
Go to Account > Orders, choose the order and click "Start a return". Select the items and the reason, and we email you a prepaid return label. Drop the package at any UPS location. Returns are free for exchanges and store credit; a $5.95 label fee is deducted from cash refunds.

## Refund timing
Refunds are issued to the original payment method within 3 business days after the warehouse receives your return. Your bank may take another 5-10 business days to show the credit. Store credit refunds are instant.

## Exchanges
To exchange for a different size or color, start a return and choose "Exchange". We ship the replacement as soon as the return label is scanned, so you do not have to wait for the original item to arrive.

## Used or worn gear
Gear that has been used outdoors can be returned within 60 days only if it is defective. Non-defective used items are not eligible, but you can trade them in through the Fernway Re-Gear program for store credit.
