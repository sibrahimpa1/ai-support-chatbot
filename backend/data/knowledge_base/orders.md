# Orders

## Checking order status
You can check the status of an order under Account > Orders, or ask the support assistant with your order number (it looks like FW-10234). Order statuses are: Processing, Shipped, Out for delivery, Delivered and Cancelled.

## Changing or cancelling an order
Orders can be changed or cancelled within 1 hour of being placed, as long as they have not started processing. Open the order under Account > Orders and click "Cancel order". After that window the order is already being packed, so please wait for delivery and start a free return instead.

## Changing the shipping address
You can change the shipping address within 1 hour of placing the order. After the order ships, you can redirect the package through the carrier using the tracking link, which may add a small carrier fee.

## Missing items
If an order arrives with missing items, check whether the order was shipped in multiple packages; the confirmation email lists every package. If an item is still missing, contact support and we will ship it right away at no cost.
